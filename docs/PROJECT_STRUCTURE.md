# PracTrack Project Structure

- `backend/`: Express API, MongoDB connection entry point, utility functions, and backend tests.
- `frontend/`: React/Vite interface, reusable components, styles, and frontend tests.
- `.github/workflows/ci.yml`: backend and frontend CI jobs.
- `docs/`: editable diagrams and PNG previews.
- `.env.example`: fake local configuration values only.

This is a starter scaffold. The student/coordinator authentication, student records, time-entry CRUD, approval workflow, progress dashboard, real deployment URLs, branch protection, PR evidence, and final screenshots still need implementation and verification against Activity 15.
